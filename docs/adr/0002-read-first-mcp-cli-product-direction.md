# ADR 0002: Keep the Next Product Stage Read-First and MCP/CLI-Centered

Status: Accepted on 2026-09-04.

The project will pursue broader adoption for Evidence Users and Workflow Integrators by improving and expanding its Bilibili capabilities, while keeping Reading Capability as the primary product family and the MCP/CLI Capability Layer as the product surface. Built-in notes, commentary generation, RAG, and an end-to-end Web UI are not part of the next stage. Account Mutation is not rejected, but any creator-oriented mutation capability requires a separate product, official-platform, authorization, safety, and acceptance decision rather than being added as a routine extension of an existing read tool.
