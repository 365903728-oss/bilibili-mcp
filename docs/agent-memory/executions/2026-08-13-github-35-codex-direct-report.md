   and Codex–Paseo–Claude projections.

   accepted-and-committed provenance in a separate Evolution task.
8. Hook: replay, shadow, no-secret, multi-worktree, canary, and rollback checks
   operate on the deployed public handler, attributed ledger, manifest, and
   configuration snapshots and are required as promotion evidence.
9. Loop: bounded attempts, no-progress stop, user-input yield, and no adapter
   switch are enforced by the public step seam.
10. Immutability: the #34 fixed evaluator, holdout, protected-path, and
    self-approval checks remain mandatory.
11. Failure: known candidate state restores exact prior Git blobs/modes;

    remote authority remains absent.
