# v1.13.1 — ASR GPU 加速与 Fake-IP 诊断 / ASR GPU Acceleration and Fake-IP Diagnostics

## 中文

- ASR 模型选择新增“速度优先 / 均衡 / 质量优先”说明，`small` 继续作为默认推荐。
- 新安装默认使用 `auto`：真实验证 `cuda/float16` 成功就使用 NVIDIA GPU，否则以脱敏类别说明原因并继续使用已验证的 `cpu/int8`。显式 `cuda` 失败不会静默回退。
- 旧 v1 安装会在升级后的第一次明确 ASR 请求中完成一次设备迁移；无需重新下载模型，同一次请求直接使用迁移后的 GPU 或 CPU Profile，之后不重复探测。
- `doctor --json` 报告实际模型、设备、compute type、readiness、迁移状态和可选失败类别；成功 transcript 与 MCP schema 不变。
- 修复 Node.js 25 的 DNS lookup 数组契约；新增 `ASR_FAKE_IP_DNS`，让 Agent 解释 Fake-IP 原因并提供 Bilibili 域名 real-IP / `fake-ip-filter`、`redir-host` 或暂不使用 ASR 的选择，无需关闭整个代理。

## English

- ASR model selection now explains speed-first, balanced, and quality-first tiers while keeping `small` as the recommended default.
- New installs default to `auto`: use NVIDIA `cuda/float16` only after real readiness succeeds, otherwise report a sanitized category and continue on verified `cpu/int8`. Explicit `cuda` never falls back silently.
- Existing v1 installs migrate once on the first explicit ASR request after upgrade without downloading the model again. The same request immediately uses the migrated GPU or CPU Profile, and later requests do not probe again.
- `doctor --json` reports the actual model, device, compute type, readiness, migration status, and optional failure category; successful transcript output and MCP schemas are unchanged.
- Fixed the Node.js 25 DNS lookup array contract and added `ASR_FAKE_IP_DNS`, allowing Agents to explain Fake-IP and offer Bilibili-domain real-IP / `fake-ip-filter`, `redir-host`, or no-ASR choices without disabling the whole proxy.
