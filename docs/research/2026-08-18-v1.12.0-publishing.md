# Research Note: v1.12.0 Trusted npm Publishing

## Research Topic

- Date: 2026-08-18
- Owner: Codex
- Related ticket: `REL-2026-08-18-V1.12.0`

## Question

Can the existing tag-triggered workflow publish `1.12.0` through npm trusted
publishing without a workflow or credential change?

## Sources

| Source | Type | Date checked | Notes |
|--------|------|--------------|-------|
| https://docs.npmjs.com/trusted-publishers/ | official npm docs | 2026-08-18 | GitHub-hosted runner, OIDC, npm 11.5.1+, Node 22.14.0+ |
| https://docs.github.com/en/actions/tutorials/publish-packages/publish-nodejs-packages | official GitHub docs | 2026-08-18 | `id-token: write` and registry setup for npm publication |
| `.github/workflows/publish.yml` | repository source | 2026-08-18 | Pins Node 22.14.0 and npm 11.18.0; grants only `id-token: write` and `contents: read` |

## Findings And Decision

- The existing workflow already satisfies the current trusted-publishing
  runtime and OIDC requirements.
- No npm token, dependency update, or workflow change is required.
- Push the annotated tag only after local release verification; create the
  GitHub Release only after the tag-triggered npm publication succeeds.

## Refresh Before

Refresh this note if the publish workflow, npm trusted publisher, runner, or
package ownership changes.
